Zapret Helperby plyushkin96

Помощник для обхода DPI

Следит за сетью любого приложения (и его дочерних процессов) и показывает адреса, к которым оно обращается.

Как работает

  1. 1Выберите .exe приложения — помощник будет ждать его запуска.
  2. 2Запустите приложение — анализ начнётся сразу.
  3. 3Справа появятся адреса: домен, IP:порт, протокол. Домены берутся из DNS-кэша Windows, записи от дочерних процессов помечены меткой child.
  4. 4Нажмите Копировать — список готов для конфига zapret.
Если приложение перезапустится — слежка продолжится автоматически.
🔒
Для отображения имён хостов нужно включить DNS-логирование
