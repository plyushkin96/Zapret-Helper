Zapret Helper — составление list-файлов для обхода DPI
========================================================

Приложение автоматически проверяет и настраивает DNS-логирование
при первом запуске — подтвердите UAC если появится запрос.

Для любого .exe: выберите файл, запустите приложение —
помощник покажет все серверы (домены и IP).

СОДЕРЖИМОЕ
---------
- Zapret-Helper.cmd — ГЛАВНОЕ: запуск десктопного приложения
  "Zapret Helper by plyushkin96" (C# WPF + WebView2). Подходит для
  ЛЮБОГО приложения: нажимаете «Выбрать .exe», указываете файл —
  помощник ждёт его запуска, анализ начинается сразу.
  Слежка идёт и за дочерними процессами (WebView2, Electron и т.д.).
  При перезапуске приложения слежка продолжается.
  Работает без прав администратора.

Копирование отдаёт чистый столбик доменов для list-файлов zapret.
